# Registro de uso de IA — ALERTASP SOA

Este arquivo registra o uso de IA como copiloto, conforme a orientação geral da FIAP.
A equipe deve acrescentar os prompts realmente utilizados durante suas alterações e
explicar o código que manteve no projeto.

## Prompt inicial de arquitetura e implementação

"Atue como arquiteto e desenvolvedor Java/Spring Boot para a entrega de SOA da Global
Solution CitizenTech. Proponha uma API REST em camadas para o ALERTASP, com domínio
pequeno de pontos de monitoramento e ocorrências de alagamento, PostgreSQL, migrações
Flyway, Swagger/OpenAPI, validação, tratamento de erros e testes automatizados. Não
presuma integração com o CGE e identifique dados demonstrativos. Explique cada decisão
para que estudantes consigam defender o código."

## Como manter este registro

- Adicione a data e o objetivo de cada prompt novo.
- Registre o que foi aproveitado, alterado ou descartado.
- Não registre dados pessoais, credenciais ou tokens.
- Não entregue código que a equipe não consiga explicar.
